# 文案维护指南

网站所有个人信息和项目文案集中在 [`portfolio.ts`](./portfolio.ts)。修改并保存后，本地预览会自动更新；之后执行正常构建即可部署到 Vercel，不需要把文案复制到其他文件。

## 最常修改的位置

- `SITE_CONTENT`：姓名、邮箱、身份、首页提示、联系区标题和页脚说明。
- `summary`：项目列表里的简短介绍。
- `achievement`：项目列表里“成果”后面的简短成果。
- `details.intro`：点开项目后“游戏介绍”的正文。
- `details.work`：点开项目后“具体工作”的项目符号列表；每增加一条工作内容，就增加一个 `{ zh: "...", en: "..." }`。
- `details.result`：点开项目后的完整成果说明。
- `details.tools`：详情页的工具和能力标签。

## 编辑规则

1. 中文写在 `zh` 后，英文写在 `en` 后。
2. 文案必须保留引号、逗号和花括号；正文中的英文双引号请写成 `\"`，中文引号“”可以直接使用。
3. `id`、`cover`、`media` 和 `downloadUrl` 与文件路径及链接有关，不改文案时不要调整。
4. 图片和视频继续在 `public/media/<项目>/` 中维护；网页引用的是以 `/media/` 开头的路径，兼容本地预览与 Vercel。
5. 保存后如果页面没有立即更新，刷新浏览器即可。正式部署前应运行一次构建检查，语法错误会被直接指出。

## 简介与详情可以不同

列表中的 `summary`、`achievement` 与弹窗中的 `details.intro`、`details.result` 是独立字段。可以把列表文案写得精炼，把详细说明放进 `details`，互相不会覆盖。
